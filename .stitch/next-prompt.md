# Final App Integration & Full Production Test Flow

**Page Goal:**
Review and test the entire user workflow from Onboarding, Role Selection, Authentication, and the Dashboard Hub, to the interactive study/quiz sessions and profile progress screens, ensuring consistent design systems and fully integrated navigation.

**Key Components:**
1. **Unified Device Preview Navigation**: Connect all 10 screens seamlessly in the sidebar selector and nav tabs.
2. **State Syncing**: Ensure state transitions (like XP updates, role selections, and login success) carry over across views.
3. **Responsive Viewports**: Verify mobile rendering across iOS (iPhone 15 Pro, 13 Pro Max) and Android (Pixel 8 Pro, Galaxy S24) in the inspector panel.
4. **Theme Transitions**: Verify dark mode visual consistency across all pages.

**DESIGN SYSTEM (REQUIRED):**
We must adhere to the StudPal design system rules:
- **Philosophy**: Clean, motivating, supportive, smart, slightly playful, and premium but approachable.
- **Colors**:
  - Primary: `#112B8A` (Deep Royal Navy)
  - Brand Accent Orange: `#FF5B00` (Vibrant Action Orange)
  - Secondary / Muted: `#8F95A5` (Cool Slate Muted)
  - Accent / Links: `#2D62FF` (Bright Royal Blue)
  - Surface (Light): `#F7F8FA`
  - Background (Light): `#FFFFFF`
  - Text (Light): `#0B0B0F`
  - Success: `#22C55E`
  - Error: `#EF4444`
  - Warning: `#F59E0B`
- **Typography**: Inter font family, clean visual hierarchy.
- **Layout**: MOBILE device, base spacing unit 4px, standard border radius 12px. Mobile-first clean layout with safe areas.
