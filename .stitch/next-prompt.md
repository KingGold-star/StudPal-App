# Study & Spaced Repetition (SRS) Flashcards Screen (Screen 10)

**Page Goal:**
Deliver an interactive, high-retention Spaced Repetition (SRS) review session using 3D card flip animations, SM-2 algorithm rating buttons (*Again*, *Hard*, *Good*, *Easy*), Pomodoro focus timer header, and session completion reward stats.

**Key Components:**
1. **Active Session Header**: Subject title (e.g., "Calculus II - Derivatives"), card counter progress bar (e.g., "Card 4 of 15"), and live Pomodoro focus timer widget.
2. **Interactive 3D Flashcard**: 
   - **Front**: Question/Concept text, LaTeX formulas, code snippet, or diagram.
   - **Tap to Flip**: Smooth animated transition revealing the **Back** (Answer, step-by-step solution, key takeaway, audio pronunciation button).
3. **SM-2 Spaced Repetition Rating Bar**:
   - **Again (<1m)**: Red button — reset card interval.
   - **Hard (2d)**: Orange button — slight interval increase.
   - **Good (4d)**: Blue/Green button — standard SRS interval.
   - **Easy (7d)**: Purple button — long interval jump + bonus XP.
4. **Quick Tools Bar**: AI Explain card button, Hint button, Bookmark card, and Audio listen action.
5. **Session Complete Reward View**: XP gained breakdown, retention rate %, streak increment animation, and "Return to Study Hub" CTA.
