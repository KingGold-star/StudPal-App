# StudPal Project Constitution & Site Map

## 1. Vision & Core Value Proposition
StudPal helps students understand what they need to study, learn effectively, remember using spaced repetition, and prepare for exams with a personalized AI tutor.

## 2. Target Platforms
Cross-platform Mobile (iOS & Android via Flutter) + Interactive Web Preview on `localhost:3000`.

## 3. Core Product Pillars
1. Clean + Gamified Experience (Streaks, XP, Badges)
2. Advanced Spaced Repetition (SRS algorithm engine)
3. Notion-like Flexibility (Databases, Templates, Notes)
4. Reliable Offline-First Architecture
